# Solar Watch

## Overview
**Solar Watch** is a weather and solar data app designed for outdoor enthusiasts, professionals, and anyone needing accurate, location-based insights. It delivers real-time weather forecasts, solar data (e.g., sunrise, sunset, golden hour), and supports donations for further development.

## Features
- **Weather Forecasts**: Temperature, conditions, visibility, and humidity for 4 days.
- **Solar Data**: Sunrise, sunset, dawn, dusk, and golden hour details.
- **Responsive Design**: Optimized for desktop and mobile users.
- **User Interaction**: Contact support and donation links.
- **Location Support**: Fetches data via text, GPS or long/lat coordinates.

## Tech Stack
- **JavaScript**: Core language for logic and interaction.
- **React.js**: Component-based frontend.
- **SCSS**: Responsive styling.
- **Axios**: API integration.
- **Node.js**: Backend server for API handling and logic.
- **Express.js**: Simplified server setup.
- **Vite**: Development environment.
- **Git**: Version control.
